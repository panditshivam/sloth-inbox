Preview Markdown

A shelf suggestion, not a decision. English works best. Similarity scores are not probabilities. Short, ambiguous, negated or mixed-topic notes may land on the wrong shelf; review before using the list. Inputs are kept in memory and cleared on reload.

How it stays local. MiniLM embeddings run through Transformers.js and WebAssembly in a worker. The app downloads code and model files from jsDelivr and Hugging Face; those hosts receive normal download requests. Note text is never sent to an inference server. Internet is needed for the initial downloads and to reopen this hosted page.
